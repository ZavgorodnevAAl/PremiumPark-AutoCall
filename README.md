# AutoCall - Система автоматических напоминаний Premium Park

## Описание

Веб-приложение для автоматической отправки напоминаний о задолженности по аренде авто через WhatsApp. Система работает с API 1C для получения данных о водителях и автоматически отправляет напоминания по расписанию.

## Возможности

- ✅ **Автоматическая отправка напоминаний** по расписанию
- 📤 **Ручная отправка рассылок** в любое время
- 🧪 **Тестовая отправка** на указанный номер
- ✏️ **Редактирование шаблонов** сообщений через веб-интерфейс

## Расписание автоматических рассылок

- **Утреннее напоминание**: Каждый день в 09:00 (баланс < 0)
- **Напоминание в будни**: Понедельник-Пятница в 13:00 (баланс < -500)
- **Напоминание в выходные**: Суббота-Воскресенье в 13:00 (баланс < -500)

## Установка и запуск

### 1. Установка зависимостей

```bash
# Создайте виртуальное окружение (если еще не создано)
python3 -m venv venv

# Активируйте виртуальное окружение
# Linux/Mac:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта со следующим содержимым:

```env
# Данные для API 1C
LOGIN=ваш_логин
PASSWORD=ваш_пароль

# Данные для WhatsApp API (wappi.pro)
PROFILE_ID=ваш_profile_id
AUTHORIZATION=ваш_токен_авторизации

# Опционально: тестовый номер для тестовой отправки
TEST_PHONE=79991234567
```

### 3. Запуск веб-интерфейса

#### Простой способ (рекомендуется):

**Windows:**
- Дважды кликните на файл `start.bat`
- Или запустите из командной строки: `start.bat`

**Linux/Mac:**
- Запустите: `bash start.sh`
- Или сделайте исполняемым: `chmod +x start.sh` и затем `./start.sh`

**Через Python скрипт:**
```bash
python launcher.py
```

#### Или напрямую через Streamlit:

```bash
streamlit run app.py
```

После запуска откроется браузер с веб-интерфейсом. Если браузер не открылся автоматически, перейдите по адресу: `http://localhost:8501`

### 4. Создание .exe файла (опционально)

Для создания исполняемого .exe файла:

```bash
# Убедитесь, что установлен PyInstaller
pip install pyinstaller

# Запустите скрипт сборки
python build_exe.py
```

Или вручную:
```bash
pyinstaller --name=PremiumPark --onefile --windowed --add-data="messages.json;." --add-data="settings.json;." launcher.py
```

После сборки .exe файл будет в папке `dist/`. 

**Важно:** Рядом с .exe файлом должны находиться:
- `messages.json`
- `settings.json`
- `blacklist.json`
- `.env` (файл с настройками)

## Использование веб-интерфейса

### Главная страница
Общая информация о системе и возможностях.

### Статус планировщика
- **Запустить планировщик** - включает автоматическую отправку по расписанию
- **Остановить планировщик** - останавливает автоматические рассылки
- Показывает статус работы и следующее запланированное время отправки

### Отправка рассылок
Ручная отправка рассылок в любое время:
- **Утреннее напоминание** - отправка водителям с балансом < 0
- **Напоминание (будни)** - отправка водителям с балансом < -500
- **Напоминание (выходные)** - отправка водителям с балансом < -500

Также можно просмотреть список водителей с задолженностью.

### Тестовая отправка
Отправка тестового сообщения на указанный номер для проверки работы системы.

### Редактор шаблонов
Редактирование текстов сообщений, которые отправляются автоматически:
- Утреннее напоминание
- Напоминание для будних дней
- Напоминание для выходных дней

Изменения сохраняются в файл `messages.json`.

### Черный список
Управление черным списком номеров телефонов:
- Просмотр текущего черного списка
- Добавление номеров в черный список (вручную или из списка водителей)
- Удаление номеров из черного списка

Водители из черного списка **никогда не будут получать** автоматические рассылки, независимо от баланса.

Изменения сохраняются в файл `blacklist.json`.

## Использование через командную строку

Также можно использовать скрипт напрямую через командную строку:

```bash
# Запуск планировщика
python main.py

# Тестовая отправка
python main.py test [номер_телефона]

# Ручной запуск утреннего напоминания
python main.py morning

# Ручной запуск напоминания в будний день
python main.py weekday

# Ручной запуск напоминания в выходной день
python main.py weekend

# Справка
python main.py help
```

## Примечания

- Планировщик должен работать постоянно для автоматических рассылок
- Для работы в фоновом режиме рекомендуется использовать systemd (Linux) или Task Scheduler (Windows)
- Детальные логи отправки сообщений выводятся в консоль
- Шаблоны сообщений можно редактировать как через веб-интерфейс, так и напрямую в файле `messages.json`

## Требования

- Python 3.7+
- Доступ к API 1C
- Аккаунт wappi.pro для отправки WhatsApp сообщений
