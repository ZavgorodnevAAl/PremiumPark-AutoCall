# 🚀 Быстрый старт

## Самый простой способ запуска

### Windows:
1. Дважды кликните на файл **`start.bat`**
2. Готово! Откроется браузер с интерфейсом

### Linux/Mac:
1. Откройте терминал в папке проекта
2. Запустите: `bash start.sh`
3. Готово! Откроется браузер с интерфейсом

---

## Создание .exe файла (для распространения)

Если вы хотите создать один .exe файл для запуска на других компьютерах:

1. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```

2. Запустите сборку:
   ```bash
   python build_exe.py
   ```

3. После сборки:
   - .exe файл будет в папке `dist/PremiumPark.exe`
   - Скопируйте рядом с .exe файлы:
     - `messages.json`
     - `settings.json`
     - `.env` (с вашими настройками)

4. Запустите `PremiumPark.exe` двойным кликом

**Примечание:** Размер .exe файла будет большим (100+ МБ), так как включает все зависимости Python и Streamlit.

## Альтернативные способы запуска

### Через Python скрипт:
```bash
python launcher.py
```

### Напрямую через Streamlit:
```bash
streamlit run app.py
```

## Требования

- Python 3.7 или выше
- Установленные зависимости (см. `requirements.txt`)
- Файл `.env` с настройками (см. `README.md`)
